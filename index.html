Projects

Quantization-Aware Training
NAVER Cloud · 2024–2025
Studied QAT for low-bit LLMs to recover quantization-induced degradation. Analyzed optimization settings using perplexity, MMLU, gradient norms, and weight discrepancies.
Vision Transformer Quantization
NAVER Cloud · 2024–2025
Evaluated uniform weight-only quantization for ViTs on ImageNet across multiple bit-widths. Found 2-bit causes substantial accuracy loss while 3-bit+ preserves performance.
Binary-Coding Quantization with REM
NAVER Cloud · 2024–2025
Built a pipeline to convert FlexRound checkpoints into BCQ format and optimize alpha/offset parameters with reconstruction error minimization.
Massive Activation Analysis
NAVER Cloud · 2024–2025
Identified recurring massive activation patterns and showed propagation through residual paths. Evaluated mitigation strategies including residual-path normalization.
Speculative Decoding Analysis
NAVER Cloud · 2024–2025
Studied speculative decoding and rejection sampling; built an efficient acceptance-rate evaluation pipeline by caching verifier logits. Fixed inference issues in vLLM.
KV Cache Quantization
NAVER Cloud · 2024–2025
Collaborated on hardware-aware KV cache quantization. Implemented per-output-channel quantization and benchmarked on MMLU and LongBench.
MoE-to-Dense Distillation
NAVER Cloud · 2024–2025
Investigated distilling Mixture-of-Experts models into dense models. Expert-based initialization consistently outperformed random initialization.
Pruning & Distillation Architecture Search
NAVER Cloud · 2024–2025
Studied student architecture design for pruning and distillation. Preserving depth generally yielded better performance under matched inference-cost settings.
Compressed LLM Production

Mixed Precision & Sensitivity Analysis
